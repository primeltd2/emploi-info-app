Centre d'assistance

Consultez d'abord les réponses rapides. Si votre problème n'est pas résolu, envoyez une demande à l'administration depuis le formulaire sécurisé. Votre historique restera disponible sur cet appareil.

Avant de contacter l'administration

Les demandes les plus courantes concernent les candidatures, la publication d'offres, les formations, les actualités, les publicités, les signalements et les problèmes d'affichage. Les réponses ci-dessous peuvent vous aider immédiatement.

Questions fréquentes

Comment postuler à une offre ?

Ouvrez l'offre, lisez les détails, puis suivez les instructions de candidature indiquées par le recruteur. EMPLOI INFO diffuse les annonces, mais chaque recruteur définit son canal de candidature.

Comment publier une offre ?

Depuis l'accueil, cliquez sur "Transmettre une offre", remplissez le formulaire, ajoutez les pièces utiles, puis envoyez. L'administration vérifie l'annonce avant publication.

Pourquoi mon offre n'apparaît pas encore ?

Les offres en attente sont relues avant publication. Cela permet d'éviter les doublons, les informations incomplètes et les annonces suspectes.

Comment signaler une annonce suspecte ?

Utilisez le formulaire ci-contre avec la catégorie "Signalement". Décrivez l'annonce concernée, le lien si possible, et la raison du signalement.

Comment demander une publicité ?

Choisissez la catégorie "Publicité / partenariat" dans le formulaire, expliquez votre besoin et laissez un contact fiable. L'administration vous répondra dans l'historique.

Comment signaler une actualité ou une formation ?

Ouvrez la page détail de l'actualité ou de la formation, puis utilisez les commentaires ou le bouton de signalement. Vous pouvez aussi envoyer une demande ici avec le lien concerné.

Où voir la réponse de l'administration ?

Après envoi, revenez sur cette page avec le même navigateur et le même appareil. Vos conversations et les réponses apparaissent dans la section "Historique de vos demandes".
