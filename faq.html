FAQ

Retrouvez ici les réponses aux questions les plus fréquentes sur les offres, les candidatures, la publication d'annonces, les publicités et l'utilisation de la plateforme.

Comment postuler à une offre ?

Ouvrez l'offre qui vous intéresse, lisez attentivement les détails, puis utilisez les boutons de contact ou les instructions indiquées dans l'annonce. EMPLOI INFO partage les opportunités, mais chaque recruteur peut préciser sa propre méthode de candidature.

Comment transmettre une offre d'emploi ou de stage ?

Depuis la page d'accueil, cliquez sur "Transmettre une offre", remplissez les informations demandées, ajoutez les fichiers utiles si nécessaire, puis envoyez. L'offre est vérifiée avant publication.

Pourquoi mon annonce n'apparaît pas immédiatement ?

Les annonces sont contrôlées avant publication afin de limiter les doublons, les informations incomplètes et les contenus non conformes. Ce contrôle protège les candidats et améliore la qualité des offres publiées.

Les offres publiées sont-elles gratuites ?

La consultation des offres est ouverte aux visiteurs. Pour la publication ou la mise en avant d'une annonce, les conditions peuvent varier selon le type de contenu et le besoin de visibilité.

Comment fonctionnent les publicités sur le site ?

Les publicités sont affichées à partir des contenus enregistrés par l'administration. Elles peuvent apparaître sur l'accueil, sur une page dédiée ou dans les emplacements prévus pour les campagnes actives.

Que faire si une offre semble suspecte ?

Ne payez jamais de frais sans vérification claire. Si une offre vous semble douteuse, contactez l'équipe via la page Contact ou utilisez les options de signalement disponibles sur le site.

Comment recevoir les nouvelles offres ?

Vous pouvez suivre EMPLOI INFO sur les canaux indiqués dans le site et activer les notifications lorsque votre navigateur le propose.

Où voir les actualités ?

La page Actualités est accessible depuis le menu principal. Elle affiche des informations chargées depuis des sources définies par l'administration, avec un bouton de partage, une page détail, des commentaires et un signalement.

Les formations peuvent-elles être gratuites ou promotionnelles ?

Oui. Une formation peut être marquée comme gratuite, payante ou promotionnelle. Si une promotion existe, le prix normal peut être affiché barré avec le prix promotionnel et les conditions de durée ou de nombre de places.

Pourquoi une notification d'actualité apparaît à l'accueil ?

Lorsqu'une actualité récente est disponible, EMPLOI INFO peut afficher une petite notification pour vous inviter à lire le détail et découvrir d'autres actualités.
